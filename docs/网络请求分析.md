# 网络请求分析

## 项目概述

中山市公共资源交易平台土地交易结果公告采集。

## 页面信息

- **列表页 URL**: `https://ygp.gdzwfw.gov.cn/#/442000/jygg`
- **详情页 URL 模式**: `https://ygp.gdzwfw.gov.cn/#/442000/new/jygg/v3/B?noticeId={noticeId}&projectCode={projectCode}&...`

## 筛选条件

1. **土地矿业** (noticeSecondType: B)
2. **土地使用权交易结果公告** (tradingProcess: 3742)
3. **中山市** (siteCode: 442000)

## 列表 API

### 接口地址

```
POST https://ygp.gdzwfw.gov.cn/ggzy-portal/search/v2/items
```

### 请求方式

Playwright 真实页面操作触发，不硬编码签名参数。

### 响应结构

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "data": {
    "pageNo": 1,
    "pageSize": 10,
    "pageTotal": 24,
    "total": "238",
    "pageData": [
      {
        "docId": "xxx-yyy",
        "noticeId": "xxx",
        "noticeTitle": "...",
        "publishDate": "20260804094835",
        "projectCode": "...",
        "projectOwner": "中山市自然资源局",
        "projectType": "B01",
        "projectTypeName": "国有建设用地使用权出让",
        "siteName": "中山市",
        "siteCode": "442000",
        "tradingProcess": "3742",
        "datasetName": "成交宗地信息"
      }
    ]
  }
}
```

### 列表字段说明

| 字段 | 说明 |
|------|------|
| docId | 文档唯一标识（格式：noticeId-tradingProcess） |
| noticeId | 公告 ID |
| noticeTitle | 公告标题 |
| publishDate | 发布时间（yyyymmddHHMMSS） |
| projectCode | 项目代码 |
| projectOwner | 项目业主 |
| projectType | 项目类型编码 |
| projectTypeName | 项目类型名称 |
| tradingProcess | 交易流程编码 |
| datasetName | 数据集名称 |

## 详情 API

### 接口地址

```
GET https://ygp.gdzwfw.gov.cn/ggzy-portal/center/apis/trading-notice/new/detail
```

### 查询参数

- `nodeId` - 节点 ID
- `version` - 版本号（v3）
- `tradingType` - 交易类型（B）
- `noticeId` - 公告 ID
- `bizCode` - 业务代码
- `projectCode` - 项目代码
- `siteCode` - 站点代码（442000）

### 响应结构

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "data": {
    "rowId": 8845,
    "title": "...",
    "publishDate": "2026-08-04 09:48:35",
    "tradingNoticeColumnModelList": [
      {
        "name": "公告信息",
        "viewStyle": "keyTable",
        "multiKeyValueTableList": [...]
      },
      {
        "name": "公告内容",
        "viewStyle": "richText",
        "richtext": "<table>...</table>"
      },
      {
        "name": "相关附件",
        "viewStyle": "keyTable",
        "noticeFileBOList": []
      }
    ]
  }
}
```

### 栏目说明

| 栏目名称 | viewStyle | 数据来源 |
|----------|-----------|----------|
| 公告信息 | keyTable | DOM 表格（4行：项目名称/交易机构/受让人/公告性质） |
| 公告内容 | richText | richtext HTML 表格（含成交时间/竞得人/用地面积/成交总价/宗地位置/土地用途等） |
| 相关附件 | keyTable | 附件列表 |

**重要发现**：Vue 应用获取 API 响应后，仅将"公告信息"渲染到 DOM，"公告内容"的 richtext HTML **未渲染到 DOM**（`<div class="richtext">` 始终为空）。因此必须从 API 响应中读取 richtext 内容。

## 采集策略

### 列表阶段

1. 打开列表页 `https://ygp.gdzwfw.gov.cn/#/442000/jygg`
2. 点击筛选"土地矿业"和"土地使用权交易结果公告"
3. 监听 `POST /search/v2/items` 响应
4. 提取 docId、noticeId、noticeTitle、publishDate、projectCode 等

### 详情阶段

1. 从列表项数据直接构造详情页 URL
2. 在新标签页打开详情页
3. 使用 `expect_response` 监听 `GET /trading-notice/new/detail` 响应
4. 提取响应 JSON
5. 在 `tradingNoticeColumnModelList` 中按栏目名称查找"公告内容"
6. 解析 `richtext` 中的 HTML 表格
7. 合并 DOM 表格和 API 数据

### 字段映射

| 目标字段 | 来源 | 解析方式 |
|----------|------|----------|
| project_name | DOM 表格 + 列表标题 | keyTable: 项目名称 |
| project_code | richtext 表格 + 标题 | 宗地编号字段 / 标题正则提取 |
| transaction_date | richtext API | 成交时间 |
| winner | richtext API | 竞得人 / 受让人 |
| land_area | richtext API | 用地面积 |
| transaction_price | richtext API | 成交总价 |
| land_location | richtext API | 宗地位置 |
| land_usage | richtext API + 标题 | 土地用途 / 标题方括号 |
| transaction_agency | DOM 表格 | 交易机构名称 |
| notice_nature | DOM 表格 | 公告性质 |

## 反爬机制

- Cookie + Nonce + Signature + Timestamp 动态签名
- 旧请求返回 90004"登录凭证失效"
- Vue 前端懒加载（详情内容仅通过 API 获取，不渲染到 DOM）

## 合规措施

- 使用系统 Chrome 浏览器，让网站自行建立匿名会话
- 正常点击筛选条件，不逆向签名
- 禁止硬编码或保存 Cookie/签名值
- 出现 90004 时仅新建一次浏览器上下文，不无限重试
- 页面操作间隔 >= 1.2 秒
- 禁止并发访问
