# Evidence

- 采集过程截图
- 浏览器自动化录屏

## 说明

- 所有证据文件不应提交到 Git（已配置 .gitignore）
- 如需分享证据，请将截图/录屏文件放入此目录后本地存档
- 推荐文件命名格式: `YYYYMMDD_description.png`
